# AXZ Préstamos

**Una solución de AXZ Software Solutions para la gestión de préstamos y cobranzas.**

Bienvenido al repositorio oficial de versiones de **AXZ Préstamos**, donde encontrarás las versiones publicadas de la aplicación Android.

## 📲 Descargar la aplicación

Descarga la última versión estable desde la página oficial de releases:

**[⬇️ Descargar AXZ Préstamos — Última versión](https://github.com/agl5702/axz-loans-releases/releases/latest)**

En cada publicación encontrarás el archivo APK correspondiente, junto con su número de versión y la información de los cambios publicados.

## 📦 Instalación en Android

1. Abre la página de [últimas versiones](https://github.com/agl5702/axz-loans-releases/releases/latest).
2. Descarga el archivo `axz-loans-*.apk` de la versión que deseas instalar.
3. Abre el archivo descargado en tu dispositivo Android.
4. Si Android lo solicita, autoriza la instalación desde esa fuente.
5. Completa la instalación y abre la aplicación.

> **Importante:** descarga los archivos únicamente desde este repositorio oficial. Android puede mostrar advertencias al instalar aplicaciones mediante APK fuera de Google Play.

## 🚀 Actualizaciones

Las nuevas versiones se publican aquí cuando están listas para su distribución.

- Consulta siempre la [última versión disponible](https://github.com/agl5702/axz-loans-releases/releases/latest).
- Revisa las notas de cada versión para conocer los cambios y correcciones.
- Antes de actualizar, asegúrate de que la nueva versión sea compatible con tu entorno de trabajo.

Publicar una versión nueva no instala automáticamente la actualización en tu dispositivo. Debes descargar e instalar la APK correspondiente.

## 🔐 Integridad y seguridad

Cada versión publicada incluye su archivo APK y su suma de comprobación SHA-256, cuando está disponible, para ayudar a verificar la integridad del archivo descargado.

Las APK se compilan y firman automáticamente mediante GitHub Actions desde el repositorio privado del proyecto.
